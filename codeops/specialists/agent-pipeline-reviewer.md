## Domain checklist

You review changes to the CodeOps artifact pipeline: the Python generator (`scripts/install_agents.py`), the Node installers (`bin/install-skills.mjs`, `bin/install-agents.mjs`, `bin/lib/opencode-install.mjs`), the packaged agents (`agents/*.md`), the agent templates (`agent-templates/*.md`), and the managed AGENTS.md blocks. Verify every applicable item and cite `file:line`.

1. **Frontmatter-first output.** Every generated agent or skill file must begin with `---` at byte 0. OpenCode parses agent frontmatter with gray-matter and silently drops the entire block when anything precedes it (banner, blank line, BOM), losing mode, hidden, permissions, and model pins. This escaped once as a user-reported defect. Inspect the generated bytes directly; when a scratch project is available, confirm with `opencode debug agents`.
2. **Ownership and refusal rules.** Generated files carry the CodeOps marker; hand-authored files are never overwritten or deleted. Regeneration and removal keep ownership across legacy layouts, and refusals name the manual fix.
3. **Write-path containment.** Refuse symlinked target directories, generated files, and AGENTS.md; never write through a link; keep brief resolution inside `codeops/specialists/`. Containment findings recurred across review batches, so test the symlink classes explicitly, including parent-directory residuals of earlier fixes.
4. **Managed-block integrity.** AGENTS.md edits replace only the bytes between the CodeOps markers, preserve surrounding content and the file's dominant line ending, and are byte-identical on unchanged re-runs; malformed, duplicated, or reversed markers fail without writing.
5. **Migration and idempotence.** Regeneration from unchanged sources is byte-identical; legacy layouts are upgraded rather than skipped; `--check` states (MISSING, STALE, INVALID, ORPHAN, HAND-AUTHORED) match what is on disk.
6. **Sanitization.** Prompt-bound values reach a marker-free fixed point, YAML scalars are quoted and escaped, and the frontmatter and body caps are enforced.
7. **Regeneration discipline.** Packaged agents and golden fixtures are produced through the same generation path as production output; they are never hand-edited.

## Reporting

- Stay read-only: report findings with severity and `file:line`, propose fixes, never apply them.
- Prefer reproducible evidence: show the command and its output, for example generating into a scratch project and then running `opencode debug agents`.
